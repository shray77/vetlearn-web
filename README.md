# VetLearn AI — статическое демо

Стабильная ссылка: **https://shray77.github.io/vetlearn-web/**

Автосборка (static export) из [gitlab.com/shray77/vetlearn-web](https://gitlab.com/shray77/vetlearn-web) `main`.
Исходники и серверная версия — там же (полная версия с ИИ живёт на отдельном хостинге).

Это офлайн-версия: ИИ-генерация заменена резервным контентом через
клиентский офлайн-шим `OfflineApiBridge` (включается флагом сборки
`NEXT_PUBLIC_OFFLINE_API_BRIDGE=1`, живёт в исходниках: `src/lib/offline-api.ts`).

## Сборка экспорта

Пайплайн: `scripts/vl158_build_pages.sh` (Task 158) — копия исходников,
`output: 'export'` + `basePath: /vetlearn-web`, флаг офлайн-моста, без
API-роутов/middleware/SW (на Pages они мертвы), манифест под basePath,
`.nojekyll`, `_not-found.html` → `404.html`.

⚠️ Старый деплой-скрипт рабочей машины (`scripts/vetlearn_static/…`)
больше не нужен: мост, который он вливал в бандл, теперь включается
флагом сборки; запуск старого скрипта перезапишет нативный ДС.

Не коммитить сюда исходники — ветка gh-pages только для Pages.
